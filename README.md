Скрипты:
1. table_preprocessor.py преобразует таблицу xlsx в grid таблицу markdown
при этом один файл xlsx на одну таблицу, название листа где таблица по умолчанию ("Лист1")
должен быть лист с названием таблицы и тэгом ("Info") формирует название таблицы и тэг. 
Например 
Название таблицы | Бла бла бла
Тэг              | TableTag

будет добавлена строчка : Тестовая таблица {#tbl:test}

Содержимое таблицы должно быть между тэками
<!-- INSERT_TABLE: file=gzsign1.xlsx -->
<!-- END_INSERT_TABLE -->
Здесь file название файла с таблицей.


2. Postprocess.py
Оптимизирован, можно в пределах одного типа добавить подтип , ищет в заголовке подтип , например "Iторм".
Изменен алгоритм
3. table_generator 
доработан алгоритм определения однострочного столбца, при слияниях ячеек второй и третьей строк не правильно отрабатывал
